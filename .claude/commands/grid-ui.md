Построй/улучши табличный редактор — центральный UI аналога Коммандера. Контекст
запуска: `$1` (если пусто — общий переиспользуемый грид в `src/renderer/shared/grid/`).

## Референс интерфейса (как в Директ.Коммандере)

- Слева — **дерево аккаунт → кампании → группы**; выбор узла фильтрует таблицу
  справа.
- Справа — **таблица** объектов выбранного уровня (кампании / группы / объявления
  / ключевые слова), переключаемая вкладками.
- Таблица большая (тысячи строк) — обязательна **виртуализация**.

## Требования

1. **TanStack Table + TanStack Virtual**: сортировка, изменяемая ширина колонок,
   выбор/скрытие колонок, множественный выбор строк (checkbox + shift-range),
   фильтр по колонкам, быстрый поиск.
2. **Инлайн-редактирование** ячеек с валидацией на лету (используй `core/validation`).
   Изменённая, но не сохранённая ячейка подсвечивается.
3. **Индикатор `sync_status`** в строке: цвет/иконка для
   `synced / new / modified / deleted / conflict`. Конфликтные строки кликабельны
   → панель разрешения конфликта (локальное vs серверное, по полям).
4. **Панель баллов (units)**: остаток баллов Директа виден постоянно (данные из
   клиента API), чтобы пользователь понимал бюджет на синхронизацию.
5. **Тулбар**: кнопки Pull / Push / выбор аккаунта (Client-Login), статус
   последней синхронизации и прогресс (стрим из `SyncEngine`).
6. Всё общается с main только через `window.api` (IPC). Renderer не трогает БД/API
   напрямую.
7. Доступность и клавиатура: навигация стрелками, Enter — редактирование,
   Esc — отмена.

## Критерии готовности

- 10k строк скроллятся плавно (виртуализация работает).
- Правка ячейки меняет строку в `modified` и подсвечивает её.
- Панель баллов и статус синхронизации отражают реальные данные движка.
- Дерево слева фильтрует таблицу.

Не коммить — покажи структуру компонентов грида и как он переиспользуется в
фичах сущностей.
